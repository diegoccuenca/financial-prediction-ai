
# Financial Prediction AI

A Python machine learning project focused on financial
data analysis and revenue prediction.

## Technologies
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Current Features
- Financial data analysis
- Data visualization
- Linear Regression
- Multiple Linear Regression
- Train/test evaluation
- Mean Absolute Error (MAE)

## Future Development
- Neural networks
- Deep learning with PyTorch
- Evolutionary algorithms
- Automatic neural network architecture optimization

## Dataset
Currently uses a small synthetic dataset for learning
and experimentation.
